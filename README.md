# Tree of Staff

Десктопное приложение на **Java Swing**: иерархический справочник сотрудников в виде дерева с группировкой по первым буквам фамилии (латиница A–Z), форма карточки сотрудника, поиск и сохранение данных в файл.

Исходно проект сделан в 2013 году (курс ВМК / БИ ВШЭ); код приведён к более безопасной работе с файлами и исправлению логики.

## Возможности

- Дерево тем по префиксам имени (динамическое расширение веток при переполнении).
- Карточка: ФИО, дата рождения, табельный номер (маска), адрес, путь к фото.
- Поиск по полям (последовательный обход совпадений).
- **Файл → Открыть / Сохранить как** — сериализация списка сотрудников в поток объектов (`ObjectOutputStream` / `ObjectInputStream`).
- Смена Look & Feel из установленных в JRE.

## Требования

- **JDK 8+** (для сборки через Maven указаны `source`/`target` 1.8).
- Зависимость **MigLayout** подтягивается Maven’ом: `com.miglayout:miglayout-swing` (актуальная версия в `pom.xml`, напр. **11.4.3** с [Maven Central](https://central.sonatype.com/artifact/com.miglayout/miglayout-swing)).

## Сборка и запуск

```bash
mvn compile
mvn exec:java
```

Точка входа: `ru.hse.bi1.tree.Main`.

## Формат данных

Файл сохранения — последовательность сериализованных объектов `Employee` (не JSON). Для обмена данными между версиями используйте одну и ту же версию классов или мигрируйте формат отдельно.

## Известные ограничения

- Подписи тем и разделение в дереве завязаны на **латиницу** в первой строке представления записи (как в исходной логике).
- Изображение по умолчанию: `default.jpg` в рабочей директории при пустом пути к фото.
